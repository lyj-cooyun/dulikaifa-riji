# 遥远的回忆
一个开发群里讨论起了 Java ，我才想起来上大学的时候我还考了一个 Sun 的 J2SE 认证，于是把证书翻出来，拍照留念。我当年学的还是 JDK 5 （其实也是 1.5 ，估计很多年轻人都不知道这个典故了），我查了一下现在最新的都已经是 23 了……

当年为了这个认证考试，买教材，买题库，一整个暑假都在准备这个事情。记得那年是大二，学院里开了个优秀学生的分享会，一个大三的学长分享了他开发手机软件（ J2ME ）并且赚了不少钱的事例，这把当时的我羡慕得不得了，于是我就决定在 Java 这条路上走到黑。不知道从哪里听说考一个 Sun 的认证对于将来找工作很有用，我就报名了。

考点离学校很近，就隔着一条三好街，好像是在一个书店的二楼，专门有一个特别小的屋子一台电脑用来认证考试。考试过程和驾照的机考很像，好像是 90 分以上就算通过，答完题当场出结果。

后来，我无论考研和找工作都把这个证书放到申请资料里，也不知道是否有用。从本科到硕士再到第一份工作，我的绝大部分代码都是写 Java 。随着转为 iOS 开发者，我也快 10 年没写过 Java 了。去年安卓小哥把极简便签安卓版交给我，我打开源代码，刚写了一句简简单单的赋值语句，IDE 就报错，我仔细一看，源代码居然不是 Kotlin 而是 Java…… 真是相见不相识了。

# Nut Goals
Nut Goals 这周的主要工作就是加入了中文本地化和新的小组件。
之前参赛为了节省时间，就只写了英文本地化，很多文案没有考虑到中文语境，而现在就遇到了一些麻烦。若是把英文文案直译成中文，很多地方就很不通畅，甚至诡异。

![]( https://files.mdnice.com/user/73796/c171df2e-f8b7-45c5-8635-2857e9a7932f.png)

还给 Nut Goals 的首页加入了直接打开记账页面的按钮（居然没在第一版就加入，我也是很奇怪），还添加了两个可以直接打开记账页面的小组件。小组件寸土寸金，有时候要为多一个字母少一个字母来不断更改设计布局。

下周的开发计划是：
- 新建记账的锁屏小组件
- 新建记账的控制中心小组件
- 优化账户概览的小组件
- 加入更多分类的图标和中文本地化
- App Store 里加入中文本地化，App 描述和截图等

做完这些感觉就可以发一个版本了。
