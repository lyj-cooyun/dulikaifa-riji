## 善用互联网工具的父亲

这周孩子的学校要求每人都要参加一个画画比赛，在线提交一个作品，主题是爱家乡。提交的过程是先关注一个公众号，然后跳转到一个小程序，我一看这套路明显就不是什么正经比赛，于是就想着敷衍了事。一开始我还想在网上随便搜一张图片交上去，但是想想这样对原作者也是不太尊重，于是就用 Stable Diffusion 生成了十来个，挑了一张交了上去。

![]( https://img.way2solo.com/photo/vulgur/6c35f0d9-4b1c-449d-a080-88c5cd3bf4ed.jpeg?imageView2/2/w/1920/q/100)


众所周知，很多商家为了宣传自己，都让用户在朋友圈集赞，然后给用户一些优惠或者礼品。我和老婆都特别讨厌这种手段，之前所有这样的活动都是坚决不参加，但是娃的兴趣班也搞了这么个集赞活动，抓住了小孩子的心理，让父母集赞 28 个就可以送给孩子一个小礼物。为了让孩子得到礼物，我找到了一个「朋友圈转发截图生成工具」，分分钟就完成了这个任务。无独有偶，孩子前些天拍摄写真的影楼也让集赞，可以多添加一些照片入册，于是还是使用这个工具，大成功！

![]( https://img.way2solo.com/photo/vulgur/c662fdf9-b37b-42c5-a0a9-fc2a44edb9e5.jpeg?imageView2/2/w/1920/q/100)

### 微信支付服务端

这周前几天的焦虑来自于极简时钟国内安卓版的服务端。

这个服务端写于两年前，当时为了节约成本，并没有购买云数据库，而是采用了 Parse Community 的开源项目作为 app 的数据库，只是用来存放极简时钟的支付记录。后来的极简日记就直接使用了云数据库，我就一直想着把 parse 里的数据都迁移到云数据库中，顺便统一两个 app 的 API 。

旧版的支付 API 是构建于微信支付 v2 版本的，使用的开源库也已经多年不更新了，虽然一直以来没出现任何问题，但是想着未来会拓展 API ，还是决定想在 AI 的帮助下重写极简时钟的服务端。

我一直很恐惧写后端，特别是涉及支付和数据库，就怕出事。所以后端的开发我是能拖就拖，得过且过，这也是这么久都没将迁移和升级工作付诸行动的原因。

我先是想在 ZFC 的后端项目里新建一个 v2 版本的 API ，但是写了一晚上发现代码量还不少，特别是数据库中关于读写的代码，写到后来恐惧的心理直接就将我击溃了。

后来我整理了一下思绪，突然意识到最稳妥的办法就是复用极简日记的 API ，于是在极简日记的后端项目里为 ZFC 新建了一套 API 。只花了不到半天就把新 API 写好了，还在 AI 的帮助下，整理了一下原来的代码和配置信息。最后在本地测试了一下，所有的新 API 都跑通了，这时所有的焦虑才大大缓解。

## 极简日记 iOS ([App Store]( https://apps.apple.com/cn/app/id1568936702))

这周提交了 1.7.5 ，修复三个 bug ，更新一波关键词。

Backlog 里一直有一个想做的重磅功能，至少我还没发现其他日记 app 有做的，准备下周开始动手。

## iPad mini 6

我手里的 iPad Air 2 最近基本都在吃灰，之前除了给孩子下围棋用，也就是开发 app 时为了适配 iPad 才拿出来。现在孩子也不学围棋了，系统也没法升到 iPadOS 16 ，在我这里也没什么用处了。正好我妈的 iPad 3 终于坏了，这个 iPad Air 2 就给她用了。

于是就开始物色新的 iPad 测试机，最后选择了 iPad mini 6 ，便携而且性能足够用。在闲鱼上调研了两天，选中了一个信用优秀而且百次好评的卖家，没有犹豫直接下单了，没想到卖家在我付款后又说了一堆有的没的， 说什么其实是替妹妹卖的，现在的价格太便宜，怕妹妹不高兴，让我申请退款，他提高些价格再让我拍下，然后再把多出来的部分退给我……我去你的吧，退款后直接拉黑。

后来又选择了价格更低的一个卖家，选择了验货宝，希望不会被坑。可以预见的连带消费还会有各种配件，外壳、支架、Apple Pencil……
