# 本周工作

## 极简日记 iPad/Mac

这周主要的开发都是在继续完善极简日记的 iPad/Mac 版，终于是差不多完成了，下周就可以进行 TF 测试了。iOS 版的大部分功能都实现了，剩下的就不能再闭门造车了，需要用户的真实反馈。

这个分支写了好久，主分支也更新了几个版本，合并的话定然会产生很多冲突，一想到手动解决各个冲突和看到很多 <<< HEAD 我就头疼，所以我这次大胆地交给了 AI ，让它进行合并和解决冲突。结果还不错，只有一个编译错误，还有两个被 iOS 和 Mac 都复用的页面 UI 出了点小问题，还没发现其他问题。


[图片]


## App Store Connect API

继续开发上周开始的 ASO 分析工具，我觉得应该先有 App 数据才能分析，所以这周只是实现了通过 App Store Connect API 来获取 App 的下载量和收入。

不知道为什么，Codex 对于这一套 API 的运用很差，即使我把官方文档和其他 blog 示例喂给它，还是写不好。前前后后拉扯了半天，差点把周额度都耗光才勉强写好。

一开始还出现了数据计算错误，直接把我的收入写成了 7 天收入 20 多万美元😂，吓我一跳。

# 代码之外

## 游戏

周一终于又通关了一次《黑神话悟空》。本来以为最后的大圣残躯又要打很久，没想到第二次就过了，还没有打石猿的次数多（估计打了十多次），二郎神也是打了几次就过了，感受到了熟能生巧的成就感。

黑猴之后，又继续玩《最后生还者 Part 2 》，周六晚上通关了，但是奖杯完成率居然只有 36%，想要白金的话，又要对着全收集攻略慢慢搜刮了。

## 谁是凶手

接着《谁杀了她》读完了《我杀了他》，不出所料，结尾也是没有揭示谁是凶手。这本书的豆瓣评分比《谁杀了她》还低了 0.2 分，但是我觉得这本书的故事性更好，案件更复杂，嫌疑人的个数也多了一个。虽然最后没有指出谁是凶手，但是书里给出的各种细节足够推理出真正的凶手是谁，这一方面比起《谁杀了她》更确定，没有那么多争论。


[图片]


## 骑士精神
一口气看完了《七王国的骑士》，乔治老爷子跟《龙之家族》剧组闹掰了，就把精力转向了这部剧，才有了这么优秀的影视作品。每集只有半个小时，一共六集，看起来非常轻松。虽然第四集在 IMDB 的打分是 10 分，但我个人认为第三集更优秀，特别是结尾对于骑士精神的两次反转，拍案叫绝！


[图片]


## 三只仓鼠

蹲了一个多星期，终于蹲到了好价，又买了个 75 基的笼子。醋有了，饺子也必须有，等待笼子送达的几天里就开始物色新的仓鼠了。第一只是布丁，第二只是虎纹，这回就想要一只期待已久的波利。在本地逛了五个卖仓鼠的摊位也没遇到喜欢的花色，没办法只能在网上买了，加了好几个卖家的微信，也看了两天小红书的直播间，发现我喜欢的卷毛肉桂波利居然最低价格是 188 ，卖家嘴里的「一张多」可比我预期的「一张多」多得多……无奈又装回了抖音，没想到在抖音的一个直播间里发现居然只卖 59 （其余的直播间还是两百左右的价格），立刻下单了。本来以为这么便宜要么货不对板，要么肯定有猫腻，没想到到手后还真是个健康美丽的红眼小卷毛。
