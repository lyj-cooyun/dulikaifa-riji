# 2024 ，0617-0623 ，第 25 周
这周前三天超级热，极端天气越来越多，发现自己耐热能力也提高了。
又到了喝冷萃咖啡的时候了，这周做了两大瓶。
健身房关闭一个多月了，没健身也一个多月了，但是体脂率和体重却再创新低。

# 本周开发
## 极简时钟 [App Store]( https://apps.apple.com/cn/app/id1265404088)
这周大部分时间还是在开发新表盘，终于是基本完成了，只剩下一些收尾和测试，还有一些上架的准备工作还没弄，这周肯定能提交了。

这次的表盘是动态变化的，会根据不同的时间来改变光影效果。为了实现这个效果，一开始和设计师商量是想着根据 24 个小时做出 24 种不同的切图，但是算上横竖屏复杂度就更大了。另外，大量的切图也会增加 App 体积。索性最后就全部用代码实现了，对着 Figma 实现设计图花费了大量的时间，虽然没能 100% 复刻设计稿，但是我感觉还算不错了。为了实现不同角度的阴影，连初中的三角函数都搬出来了。

[图片]

将表盘代码直接移植到小组件后，居然惊喜地发现，小组件上可以显示表盘的动画。我知道去年 iOS 17 对小组件加入了部分动画的支持，但是我一直没去研究和实践，没想到这次无意中触发了这个动画。

[图片]

## 极简时钟 [Google Play]([https://play.google.com/store/apps/details?id=com.mad.zenflipclock]( https://play.google.com/store/apps/details?id=com.mad.zenflipclock))

## 体验新的 SwiftUI API

从上周开始，本来计划一周做一个 code demo 的视频上传到 YouTube ，但是这周就没能完成这个目标。这周只看了一个 WWDC24 的 Session：**Creating visual effects with SwiftUI**，这个视频里讲了 SwiftUI 里五个方面新加入的 API 。我本来打算是一个方面做一个视频，结果只看了五分之一，就是第一个方面关于「滚动」的介绍。

[图片]

我想实现视频里提到的四种滚动效果设计，没想到第一个就遇到了大难题。不同大小的圆，因为外面的 frame 是统一大小的，导致圆形和圆形的间距就不一样，我花了一晚上和一上午尝试各种方法后还是无法做到统一这个间距，最后只好放弃了。其他三个还比较好实现，准备整理一下代码，下周发个视频。

# 本周体验
## 尤克里里
学习尤克里里有 20 天了，除了有两三天忙忘了，基本上每天都会练习半小时以上。
一周的时候就可以用简单的琶音弹唱《七里香》了，这周可以用分解和弦弹唱《旅行的意义》。和弦指法越来越多了，有点记不过来了，G 和弦还是很难按。最近几天在练习民谣扫弦节奏，希望下周可以弹唱《小手拉大手》。

## 厨艺大师
Chef Wang is back ！
买了一大堆日料和西餐的调料，还买了一些厨具和收纳盒，每天从小红书上学习一两道新菜。
备菜+做菜+摆拍，反馈路径短，学习成本低，自由程度高，感觉比写代码还快乐。
牛排里加入迷迭香简直好吃到爆，之前的牛排都白吃了。
