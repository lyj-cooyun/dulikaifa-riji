# 本周工作

## 竞技场模式

Windsurf 推出了一个 Arena Mode ，也就是竞技场模式，让两个不同的大模型执行同一个 prompt ，让用户最后来选择哪个大模型执行得更好。体验了一晚上感觉还挺有意思的。

用户可以自己手动指定哪两个大模型来进行对比，这个方式就是在用户明确想对比某两个大模型的情况下来使用，而另外一种匿名的对比方式就更有趣了。

针对同一个 prompt ，Windsurf 会给出两个带有化名的大模型，比如 Batman 和 Robin ，然后让这两个大模型分别建立一个 worktree 并行执行代码任务。等两个大模型都执行完后，需要用户去手动选择更好的那一个，等用户做出选择后 WIndsurft 才会显示出这两个化名究竟是哪一个大模型。

[图片]



Windsurf 在化名的设计上颇具巧思，除了上面提到的 Batman 和 Robin ，还有很多经典动画影视是搭档名字，比如 Piglet 和 Pooh 、Bonnie 和 Clyde （鸳鸯大盗）、Mickey 和 Minnie 、SpongeBob 和 Patrick 等等。

每一局对话里的两个大模型都是固定的，不是每一次输入的 prompt 都会由不同的大模型来进行对比，想更换大模型就只能新建对话，当然这也是有概率的。假如你很喜欢某个大模型，比如 Claude Opus 4.5 ， 那你就可以在这个对话里一直使用它。而且现在官网上写的是竞技场模式限时免费一周，也就是说通过竞技场模式可以像开盲盒一样免费体验到最强的那几个大模型。

## 极简时钟

前段时间在小红书上刷到一个创意时钟的设计，我感觉非常符合极简时钟的调性，所以想把这个设计加入到极简时钟的主题里。

我先是根据这个设计做了一个验证性的 demo ，还加入了深色和浅色两套主题的切换，感觉十分可行。这就看到这个小红书博主又发了一条笔记，说是这个时钟会在 3 月份进行实体的量产，于是我就私信问他可否将这个设计授权给我们，我还把 demo 给他看了一下，没想到他非常爽快地答应了。

极简时钟里最终的设计不会和他的实体版一模一样，我只是借鉴了他这个数字切换的创意。因为他的设计里只有时钟，而极简时钟还有正计时和番茄钟，所以还要加入一些极简时钟特有的布局和交互。

## 极简日记

这周提交了一个版本，是为了修复上周产生的一个 bug ，但是这次的更新又带来了一个 bug 。都是小问题，但这些小问题修改起来就比较耗时，需要针对不同版本、不同机型去一个个验证。

正好用 Windsurf 的竞技场模式对极简日记进行了两个功能点的开发。第一对进行对比的大模型是 Claude Opus 4.5 和 Kimi K2.5 ，最终胜出的是 Claude Opus 。第二对进行对比的是 Claude 自己的两个模型，Opus 和 Sonnet ，这两个在几番对阵下来互有胜负。

## 网内人

这周一口气看完了陈浩基的《网内人》，这本书是紧接着《 13·67 》之后写出来的，豆瓣上评分并不低，但是有很多网友对此书不满意的评论。这本书主要讲的就是通过黑客技术来进行破案的故事，我个人倒是对里面各种黑客技术的运用非常满意，因为作者就是计算机专业出身，所以对里面各种网络技术和计算机技术的介绍都是有理有据的，读起来令我十分信服和感叹。

而且此书已经确定影视化了，电影是邱礼涛导演，预计是 2027 年上映，改编的韩剧也已经拍摄完成了，预计是今年上映。

## 大楼里只有谋杀 S2

豆瓣评分虽然和第一季一样，但是我认为比起第一季还是要差一些，一来反派不像第一季那么出色，二来故事节奏还是一如既往的缓慢，三来这个密道的设计也太差了，要知道密道可是悬疑推理里面的一个大忌呀。虽说这个密道并没有发挥什么特别的作用，但是在一个几十年历史的大楼里面，存在着所有住客都不知道的密道，这样的设定也实在是荒诞。好在最后结局连续的两重反转，还算不错。
